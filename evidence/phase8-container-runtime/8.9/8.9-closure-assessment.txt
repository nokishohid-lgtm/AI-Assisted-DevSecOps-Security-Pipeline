Runtime Secret Handling
-----------------------
The runtime database password is no longer stored directly in docker-compose.yml.

The local .env file contains the runtime credential and is excluded from Git through .gitignore.

A safe .env.example file documents the required variables without containing a real credential.

Residual Security Considerations
--------------------------------
Container image references currently use mutable tags:

- maven:3.9-eclipse-temurin-17-alpine
- eclipse-temurin:17-jre-alpine
- postgres:16-alpine

Digest pinning is not implemented during this phase.

This is documented as a residual supply-chain hardening opportunity rather than being represented as a completed control. Future work may pin approved images to immutable digests and implement a controlled digest-update process.

PostgreSQL retains the runtime behavior required by the official image. The database was not forced into additional user or filesystem restrictions that could interfere with initialization or persistent storage.
